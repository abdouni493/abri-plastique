## 🔧 How to Maintain

### When Adding New Components
Follow this pattern:
```tsx
<motion.div 
  initial={{ opacity: 0, y: 20 }}
  animate={{ opacity: 1, y: 0 }}
  className="bg-gradient-to-br from-white to-indigo-50/20 rounded-3xl border border-indigo-100/50 shadow-xl backdrop-blur p-8"
>
  Content
</motion.div>
```

### Color Usage
- **Primary Gradient**: `from-indigo-600 to-purple-600`
- **Card Background**: `from-white to-indigo-50/20`
- **Borders**: `border-indigo-100/50`
- **Shadows**: `shadow-xl`
